# 体裁分派

## 判定
- 地图型（多玩家撞车）：同一术语多家分歧 → 先立空间再填点（harness、自我改进）。
- 锚点型（单点深挖）：单论文/单事件/单交易/单对谈 → 先深挖再造对照空间放点（persistent-mode、WikiProfile、Nvidia、fal、三本账）。
- 日常素材多为锚点型；地图型需要真实撞车（同一个词，不同的事）。

## 对照空间几何菜单（锚点型不变量：单点不进对照空间=没写完）
- 分类轴 / 2x2（竞品横向）
- 诊断阶梯（失败模式论文→运维手册）
- 情景树+决策空间（交易、监管）
- 四层判断镜（产品采用分析）
- 三本账（成本/决策分析）
- 契约清单（事故复盘）
几何随素材定；坐标系不是必需（Nvidia 篇情景树即够位）。

## 地图型附加
- 先共识后分化（共同判断作地基，再按轴分家）。
- 跨轴依赖单独成节（放大/前置关系），不许只并列。
