# 系统层模板（所有文章共享，永不逐篇重复）

## 双层 prompt 架构
- 层1（本文件 + FRAMEWORK-ACTION + QC）：系统级，稳定。
- 层2（每篇 prompt，按此组装）：
  1. 素材清单（一手源+日期）
  2. 一个框架动作（借/复用/注入）
  3. 2-3 条特异性条款（本篇的锚定数字、人物、钩子）
  4. 体裁标记（map | anchor）
  层2保持极短；修辞由模型自带。

## 七拍骨架（双体裁通用）
1. 钩子：具体场景/异常信号/反直觉坦白。埋入贯穿全文的实体比喻。
2. 纠偏：点名流行读法，用一手源原话纠正（引用原文，标出被丢掉的限定词如 current）。
3. 证据基线：已证明 vs 未证明；双口径分开；列出没人公开过的数据。
4. 框架时刻：把点放进对照空间（见 GENRES / FRAMEWORK-ACTION）。
5. 算账：论点换算成数字；重算对方口径；一个锚定数字贯穿全文反复出现。
6. 反方证据+诚实条款：失败案例映射回框架格子；混杂因素；信源折扣（见 QC）。
7. 边界+工具交接：本文不适配谁；给读者阶梯/清单/判读规则；回收开场比喻（环形闭合）。

## 纪律
- 承重主张全部括号链接；收尾用计数枚举（三个问题/四层/七个信号）。
- 中文先行（站内 EN 为译版），除非另有指示。
